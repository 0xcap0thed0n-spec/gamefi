Layer stack

    Drawn bottom to top. Back sits behind the body, so packs, slings and capes read as being worn behind the character.

    Empty % is how often a layer comes back with nothing on it. Traits and their names come from the loaded filenames — the tool invents nothing.

    Rarity weights

    Weights are relative, not percentages — a trait at 20 comes up twice as often as one at 10. The share column is what it actually works out to inside its layer.

    Class gate off

    What this is: with it on, each of the five classes draws that layer only from its own set — an Enforcer never gets a Hacker's gear, so the class is readable from the art without a dedicated badge. The locked spec calls for this on the held-item layer; with held item gone, Back is the natural home for it, but nothing breaks if you leave it off.

    File setup

    • One folder per category: Background, Back, Body, Clothing, Eyes, Hair, Headwear, Face Accessory.
    • File name = trait name. Clothing/Bomber Jacket.png becomes the Bomber Jacket trait. Spaces, capitals and underscores are all fine.
    • Same canvas size on every layer so they stack. Any size works — a file that doesn't match is scaled to fit and flagged.
    • Transparent background on everything except Background. PNG or WebP.
    • Click Load folder and pick one category folder, or the top folder with all of them inside. If it came as a .zip, unzip it first.
